# Security policy

## Supported versions

Security updates are applied to the latest published prerelease and the current
`master` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include private charts, PDFs, library databases, or portable state bundles
in a public issue.

Music Tabbler processes local files and archives. Reports involving archive
path validation, checksum validation, state replacement, or unintended data
disclosure are especially useful. Include a minimal synthetic fixture whenever
possible.
