# Music Tabbler v0.2.0-beta.6

Android development prerelease for the private development repository. This
supersedes beta.5 and increments the Android version code for in-place upgrade.

## Visual transform fixes

- Connected sustain, tie, and slide ink that crosses an inserted-string seam
  moves as one component instead of being split into vertically separated
  fragments.
- Replacing a detected fret, including a parenthesized sustain fret, preserves
  adjacent curve ink while still removing the stale source glyph.
- Added string lines infer the staff's horizontal bar boundaries and stop at
  those boundaries instead of extending into the page margins.
- Tuning-label cleanup reuses the detected staff boundary so it does not erase
  the start of a newly added string.
- System crops retain a small horizontal safety guard for notation that reaches
  just outside detected staff geometry.

## Android acceptance check

1. Install beta.6 over beta.5.
2. Open a chart containing tied or sustained notes and apply a transform that
   inserts a string.
3. Confirm every sustain curve remains continuous and is not vertically cut.
4. Confirm the added string begins and ends at the staff's bar boundaries.
5. Save and reopen the transformed chart, then export its A4 PDF and confirm
   the same curve and line geometry remains.

This is a release-mode test APK signed with the Android debug certificate; it
is not a Play Store production-signed build.
