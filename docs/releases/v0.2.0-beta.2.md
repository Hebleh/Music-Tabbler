# Music Tabbler v0.2.0-beta.2 - Android gig-workflow beta

Built from source commit `3279594` on 2 August 2026.

This beta packages the accumulated post-Apple Windows repair work and the
latest live-gig workflow improvements. It remains local-only and contains none
of the legally gated online-source adapters in LG-001 through LG-006.

## Highlights

- Full-document visual tab analysis and reviewed raster/OCR fallback repairs.
- More reliable sustained-note, fret, dead-note, and visual string-routing
  handling for local PDFs and screenshots.
- Gig pages reflow for the actual viewport, center packed row lines, and keep
  each new song on a fresh screen.
- Persistent gig zoom with visible-strip anchoring when the zoom changes.
- Stage-control lock, page-change animation, readable song headers, and
  persistent light/dark controls available directly from the setlist editor.
