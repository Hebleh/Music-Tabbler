# Music Tabbler v0.2.0-beta.5

Android development prerelease focused on preserving sustain notation during
visual string transforms.

## Visual transform fixes

- Connected sustain, tie, and slide ink that crosses an inserted-string seam
  now moves as one component instead of being split into vertically separated
  fragments.
- Replacing a detected fret, including a parenthesized sustain fret, preserves
  adjacent curve ink while still removing the stale source glyph.
- Added string lines infer the true horizontal staff boundaries when reliable
  bar-line metadata is unavailable, rather than extending through the page
  margins.
- Tuning-label cleanup reuses the detected staff boundary so it does not erase
  the start of a newly added string.
- System crops retain a small horizontal safety guard to avoid clipping
  notation that reaches just outside detected staff geometry.

## Android acceptance check

1. Install beta.5 over beta.4.
2. Open a chart containing tied or sustained notes and apply a transform that
   inserts a string.
3. Confirm every sustain curve remains a single continuous curve with no
   vertically displaced fragment.
4. Confirm the added string begins and ends at the staff's left and right bar
   boundaries instead of extending into the margins.
5. Save, close, and reopen the transformed chart, then export its A4 PDF and
   confirm the same curve and line geometry remains.

The build still reports Flutter's forward-looking Built-in Kotlin migration
warning for `desktop_drop`, `file_picker`, and `flutter_ocr_native`; it does not
prevent this APK from building or installing.
