# Music Tabbler v0.2.0-beta.7

Android ARM64 development prerelease for the private development repository.
This supersedes beta.6 and increments the Android version code for in-place
upgrade.

## Android document workflow fixes

- Songsterr share-to-Music-Tabbler and Add PDF now initialize PDF rendering
  with an explicit Android cache directory instead of failing on a null path.
- Chart and setlist PDF exports use the Android document saver.
- `.mtsong` and `.mtstate` exports preserve their exact extensions through the
  native Android save dialog.
- Positioned-PDF analysis safely offers raster/OCR review when usable PDF text
  is unavailable while preserving detected staff geometry.

## Raster review and visual transforms

- **Add note** lets users place missed normal, sustained, or `X` tokens on a
  confirmed source string without changing OCR thresholds or source pixels.
- Manual notes have local string gradients, fixed-size drag/snapping,
  remove-selected support, and review-level undo/redo.
- Manual corrections survive OCR reruns and remain horizontally stable during
  tuning and added-string transforms.
- Sustain, tie, and slide curves remain continuous when a new string is
  inserted, and the added string stops at the staff's left and right bars.

## Transform coverage

Automated checks include both presets and non-preset scenarios:

- standard four-string `EADG` to `BEADG` with an unused low B string;
- drop-C `CGCF`, source capo 1, to `BEADG`, target capo 3, with a global `+2`
  pitch change and an unused high G string;
- a selected-string-only low-E `+3` change;
- rejection of routes with fewer target strings than source strings.

## Verification

- Full Flutter suite: 288 tests passed.
- Static analysis: no issues.
- `git diff --check`: passed.
- Android emulator: PDF import fallback, all-row raster/OCR review, Add note
  dialog, and undo/redo controls were exercised.
- Local Pi/Qwen council review produced no output after more than 26 minutes,
  so it was stopped and was not counted as review.
- APK version name: `0.2.0-beta.7`.
- APK version code: `8`.
- APK Signature Scheme v2: verified.

Physical-device checks still recommended before a gig:

- share from the user's ARM-only Songsterr build into Music Tabbler;
- S Pen and palm-rejection behavior;
- keep-awake release after backgrounding and exiting Gig Mode.

This is a release-mode test APK signed with the Android debug certificate; it
is not a Play Store production-signed build.
