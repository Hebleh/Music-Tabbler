# Music Tabbler v0.2.0-beta.3

Android test release built from source commit `124c965`.

## Android import fix

- `.mtstate` and `.mtsong` imports now use Android's unrestricted system
  document picker. Android document providers cannot reliably map Music
  Tabbler's private extensions to registered MIME types, which previously made
  valid files unavailable or unrecognized in the picker.
- Desktop imports retain their extension filters.
- The portable-container reader still validates the selected file's container
  kind, schema, normalized paths, size limits, and checksums before changing
  the installed library.

## Tablet acceptance check

1. Install the APK over the prior beta.
2. Open the library-state import action and confirm the Android picker permits
   selecting `music-tabbler-library.mtstate`.
3. Import the state and confirm the Song Pool and setlists appear.
4. Open the song-bundle import action and confirm a `.mtsong` file is also
   selectable and imports as a separate song copy.

The build still reports Flutter's forward-looking Built-in Kotlin migration
warning for `desktop_drop`, `file_picker`, and `flutter_ocr_native`; it does not
prevent this APK from building or installing.
