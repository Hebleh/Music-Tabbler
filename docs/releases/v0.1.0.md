# Music Tabbler v0.1.0 - Windows MVP

Music Tabbler is a local-first visual music-chart editor for turning tablature screenshots, PDFs, and notation images into compact, stage-readable A4 charts.

## Highlights

- Import PNG, JPEG, multi-page PDF, copied Explorer files, clipboard images, or screenshot folders.
- Detect and manually refine tab/staff rows with direct move and resize controls.
- Reorder, duplicate, crop, delete, autosave, and undo visual chart rows.
- Apply original, grayscale, invert, high-contrast, or invert-plus-high-contrast display treatments.
- Highlight backing-vocal lyrics using OCR-assisted text regions or editable freeform boxes.
- Export compact A4 PDFs with minimal margins, no artificial row gaps, and optional title/artist on the first page.
- Browse saved visual drafts in the local SQLite-backed Song Pool.

## Windows assets

- `Music-Tabbler-v0.1.0-Windows-x64.exe`: unsigned user-level installer. It installs under Local AppData and creates a Start Menu shortcut.
- `Music-Tabbler-v0.1.0-Windows-x64-portable.zip`: complete portable Flutter runtime; extract it before running `music_tabbler.exe`.
- Matching `.sha256` files are provided for both packages.

Windows 10 or later and the current Microsoft Visual C++ Redistributable are required. The binaries are unsigned, so SmartScreen may display an unknown-publisher warning.

## Accepted MVP debt

- Japanese title/artist OCR is unreliable on real score headings.
- Master side-crop control positions do not persist reliably through every split-dialog action or reopening; the resulting row crops themselves are saved.
- Semantic tab recognition/editing, setlists, online source adapters, transposition, re-tabbing, portable state bundles, and Android gig mode remain future work.

See `docs/TECHNICAL_DEBT.md` for the current debt record.
