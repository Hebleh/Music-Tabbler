# Music Tabbler v0.2.0-beta.4

Android development prerelease containing the PDF import fix.

## Android PDF import fix

- PDFs shared from apps such as Songsterr no longer fail with
  `Null check operator used on a null value` during import.
- PDFs selected from Android document providers or the Downloads folder now
  use in-memory bytes when no native filesystem path is available.
- Flutter PDF rendering now uses the Flutter-aware `pdfrx` initializer rather
  than the Dart-only initializer that expects a desktop `HOME` environment
  variable.
- File imports retain safe fallbacks for local paths and readable streams, and
  report an actionable error when a provider supplies no readable data.
- Existing Windows and macOS plugin registrants were refreshed for the direct
  `pdfrx` Flutter dependency.

## Android acceptance check

1. Install the APK over beta.3.
2. In Songsterr, export or share a PDF to Music Tabbler. Confirm the Visual
   Chart Editor opens and all PDF pages are present.
3. In the Visual Chart Editor, choose **Add PDF**, select the same file from
   Downloads, and confirm all pages import without a null-check error.
4. Split at least one page into rows, save the chart, close it, and reopen it.
5. Export an A4 PDF and confirm it can be opened normally.

The build still reports Flutter's forward-looking Built-in Kotlin migration
warning for `desktop_drop`, `file_picker`, and `flutter_ocr_native`; it does not
prevent this APK from building or installing.
